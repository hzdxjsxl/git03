## 1. 产品概述

基于用户浏览行为的智能新闻推荐平台，采用"后端极简、前端智能"的创新架构。服务端仅负责特征匹配返回文章ID，前端全权处理排序、去重、无限滚动等复杂逻辑，极致优化用户体验。

- 核心价值：通过前端智能计算降低服务端压力，实现高性能新闻流
- 目标用户：追求流畅阅读体验的新闻资讯用户

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客用户 | 无需注册 | 浏览新闻，系统自动记录浏览特征 |

### 2.2 功能模块
1. **新闻流主页**：无限滚动新闻列表，动态加载推荐内容
2. **新闻详情页**：文章内容展示，自动提取阅读特征
3. **浏览历史**：本地存储阅读记录，用于推荐去重
4. **特征标签**：实时展示用户兴趣标签，可手动调整

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 新闻流主页 | 顶部导航栏 | Logo、搜索框、特征标签云 |
| 新闻流主页 | 无限滚动列表 | 虚拟滚动渲染，动态加载推荐文章 |
| 新闻流主页 | 侧边特征面板 | 显示用户兴趣标签，支持权重调整 |
| 新闻详情页 | 文章内容区 | Markdown渲染，支持图片、代码高亮 |
| 新闻详情页 | 相关推荐 | 基于当前文章特征的实时推荐 |
| 新闻详情页 | 特征提取 | 自动提取关键词更新用户画像 |

## 3. 核心流程

用户进入首页 → 前端获取初始特征词 → 调用后端匹配文章ID → 前端拉取文章详情 → 本地排序去重 → 虚拟滚动渲染 → 用户点击阅读 → 提取文章特征更新本地画像 → 滚动触发下一页加载

```mermaid

    A["用户进入首页"] --> B["前端加载本地特征画像"]
    B --> C["调用API: POST /api/recommend {features}"]
    C --> D["后端返回匹配的文章ID数组"]
    D --> E["前端批量拉取文章详情"]
    E --> F["前端处理: 排序+去重+过滤"]
    F --> G["虚拟列表渲染新闻流"]
    G --> H["用户阅读文章"]
    H --> I["前端提取文章特征"]
    I --> J["更新本地用户画像"]
    J --> K["滚动触发加载更多"]
    K --> C
```

## 4. 界面设计

### 4.1 设计风格
- **主色调**：深邃墨蓝 (#165DFF)，代表专业与信赖
- **辅助色**：活力橙 (#FF7D00) 用于强调交互，薄荷绿 (#00B42A) 标记已读
- **中性色**：多级灰度构建信息层次，深灰背景护眼阅读
- **卡片风格**：微圆角 (8px)，柔和阴影，悬浮微放大动效
- **字体**：标题使用现代无衬线字体，正文优化行高字距
- **动效**：滚动视差、入场渐显、标签云动态变换

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|----------|--------|
| 新闻流主页 | 导航栏 | 玻璃拟态背景，搜索框焦点动画，标签云悬浮效果 |
| 新闻流主页 | 新闻卡片 | 封面图懒加载渐变，标题两行截断，元信息紧凑排布 |
| 新闻流主页 | 特征面板 | 标签权重可视化，拖拽调整权重，实时反馈推荐变化 |
| 新闻详情页 | 文章阅读 | 舒适行高，首字下沉，侧边目录跟随滚动 |
| 新闻详情页 | 特征提取 | 关键词高亮动画，标签添加动效，画像更新提示 |

### 4.3 响应式
- 桌面端优先：三栏布局（特征面板 + 新闻流 + 推荐侧栏）
- 平板端：两栏自适应，特征面板可折叠
- 移动端：单栏全屏，标签折叠为底部抽屉
- 触摸优化：增大点击热区，支持滑动手势

### 4.4 性能体验
- 虚拟滚动：仅渲染可视区域DOM，支持万级列表流畅滚动
- 骨架屏：内容加载时显示占位骨架，避免布局抖动
- 图片懒加载：IntersectionObserver实现，渐进式加载
- 本地缓存：阅读记录、用户画像持久化存储
