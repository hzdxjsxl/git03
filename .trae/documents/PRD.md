## 1. 产品概述

商业合同风险排雷系统是一款基于大语言模型技术的智能合同审查工具，专为企业法务、律师和商务人员设计。系统通过上传商业合同文本，自动识别潜在风险条款，以多颜色高亮方式标注不同风险等级，帮助用户快速定位合同隐患。

- 解决的核心问题：人工审查合同效率低、易遗漏风险点、标准不统一
- 目标用户：企业法务团队、执业律师、商务谈判人员
- 产品价值：将合同审查效率提升80%以上，降低法律风险，统一审查标准

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |

| 普通用户 | 无需注册，直接使用 | 上传合同、查看风险标注、浏览规则库 |

### 2.2 功能模块

1. **合同上传页面**：文件拖拽上传、文本粘贴输入、合同类型选择
2. **风险分析页面**：分段合同展示、多颜色风险高亮、风险详情弹窗、规则依据查看
3. **规则库浏览页面**：风险规则分类展示、规则详情查看、风险等级说明

## 3. 核心流程

用户进入系统首页，选择上传合同文件或粘贴合同文本，系统从服务端获取比对规则后，在客户端执行文本差异计算和风险匹配，将合同文本格式化分段并以多颜色高亮标注风险等级，用户可点击高亮区域查看详细风险说明和处置建议。

```mermaid

    A["用户进入首页"] --> B["上传合同文件/粘贴文本"]
    B --> C["选择合同类型"]
    C --> D["请求服务端获取比对规则"]
    D --> E["客户端执行文本分段"]
    E --> F["客户端执行差异计算与风险匹配"]
    F --> G["渲染多颜色高亮标注"]
    G --> H["用户浏览风险标注"]
    H --> I["点击查看风险详情"]
    I --> J["查看处置建议"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深邃藏蓝 (#0F172A) 作为背景主色，体现法律行业的专业与严谨
- **辅助色**：
  - 高危风险：深红 (#DC2626) - 高对比度警示
  - 中危风险：橙色 (#F59E0B) - 明确提醒
  - 低危风险：金黄 (#EAB308) - 温和提示
  - 正常/建议：墨绿 (#059669) - 合规确认
- **强调色**：冰蓝 (#3B82F6) - 用于交互元素和重点信息
- **按钮风格**：微圆角 (6px)、轻微阴影、hover时背景加深+边框高亮
- **字体**：标题使用 Playfair Display（优雅衬线，体现法律文书质感），正文使用 JetBrains Mono（等宽字体，便于合同文本阅读比对）
- **布局风格**：双栏布局，左侧为操作面板，右侧为文档内容区，卡片式模块划分，充足留白
- **图标风格**：线性细线图标，统一2px描边，保持专业简洁

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 合同上传页 | 上传区域 | 大虚线边框、拖拽动画、文件图标、进度条 |
| 合同上传页 | 配置区域 | 下拉选择器、滑块控件、标签分组 |
| 合同上传页 | 操作按钮 | 主按钮悬浮动效、次按钮描边样式 |
| 风险分析页 | 合同内容区 | 纸张质感背景、段落序号、行号、段间距清晰 |
| 风险分析页 | 风险高亮层 | 背景色高亮+下划线双重标记、脉冲动画提示新识别风险 |
| 风险分析页 | 风险详情弹窗 | 毛玻璃效果、圆角卡片、渐变边框、分级图标 |
| 风险分析页 | 风险概览面板 | 环形统计图表、风险列表带颜色标签、可折叠 |
| 规则库页面 | 规则卡片 | 分级色带标识、hover上浮效果、展开详情动画 |

### 4.3 响应式设计

- **桌面优先**：针对1280px及以上屏幕优化，双栏布局
- **平板适配**：1024px时转为单栏上下布局，面板可折叠
- **移动适配**：768px以下简化操作，重点保证合同文本可读性
- **触控优化**：所有可点击区域最小44x44px，高亮区域支持触摸长按查看详情

### 4.4 动效设计

- 页面加载：内容区域从下往上渐入，错落延迟100ms
- 文件拖拽：拖入时上传区域边框高亮+背景微亮
- 风险标注：逐个高亮区域淡入，高危风险增加轻微脉冲
- 弹窗过渡：缩放+淡入组合动画，200ms缓动
- 滚动联动：点击风险列表项时，合同区域平滑滚动到对应位置
