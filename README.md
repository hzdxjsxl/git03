# 实时手语翻译系统

一个基于计算机视觉的实时手势识别系统，通过摄像头捕捉手部关键点并实时翻译为文字。

## 项目结构

```
├── main.py                    # 主程序入口
├── config.py                  # 配置文件
├── requirements.txt           # 依赖列表
├── video_processing/          # 视频流处理模块
│   ├── __init__.py
│   ├── video_capture.py       # 摄像头捕捉
│   ├── hand_detector.py       # MediaPipe手部关键点检测
│   └── feature_extractor.py   # 特征提取
├── model_inference/           # 模型推理模块
│   ├── __init__.py
│   ├── gesture_classifier.py  # 手势分类器
│   └── result_smoother.py     # 结果平滑与文本聚合
├── ui/                        # 用户界面模块
│   ├── __init__.py
│   ├── main_window.py         # 主窗口
│   └── result_display.py      # 结果展示
└── models/                    # 模型文件目录
```

## 功能特点

1. **实时视频捕捉**：使用OpenCV获取摄像头画面
2. **手部关键点检测**：基于MediaPipe，识别21个手部关键点
3. **特征提取**：归一化手部坐标、计算指尖距离和关节角度
4. **手势分类**：支持基于规则的演示模式和PyTorch模型模式
5. **结果平滑**：通过时间窗口平滑减少预测抖动
6. **文本聚合**：智能判断稳定手势并添加到文本中

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

## 使用说明

1. 启动程序后，系统会自动调用本地摄像头
2. 将手放在摄像头前，保持手掌面向镜头
3. 系统会自动检测手部关键点并识别手势
4. 保持手势稳定约1-2秒，对应的字母会被添加到翻译文本中
5. 使用右侧的"清空"和"退格"按钮可以编辑翻译结果

## 手势映射（演示模式）

演示模式基于手指伸展/弯曲状态识别字母：
- A: 仅拇指伸出
- B: 四指伸出，拇指弯曲
- C: 五指全部伸出（张开手掌）
- D: 拇指+食指伸出
- ...

## 架构说明

### 客户端-本地分离架构

- **本地处理**：视频流截帧、手部轮廓提取、关键点检测、文字平滑显示（全部在客户端完成）
- **推理接口**：接收特征张量（126维），返回分类置信度（26类）
- **网络层**：轻薄设计，只传输特征向量而非原始图像数据

## 自定义模型训练

要使用自定义训练的模型：

1. 将模型文件保存为 `models/gesture_classifier.pth`
2. 模型输入维度：126
3. 模型输出维度：26（A-Z字母）
